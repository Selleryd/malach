# Malach V7 Design System

V7 presents Malach as an autonomous profit-intelligence and governed-execution system.

## Core principles

- Dark graphite and midnight environments.
- Burnished copper for economics and opportunity.
- Violet for intelligence and authority.
- Green only for verified or healthy states.
- Consumer-first language before technical proof.
- Invented demonstration entities only.
- Rich product simulations without scroll hijacking.
- Motion uses transform and opacity only and respects reduced-motion settings.
- One major 3D hero moment; touch devices receive a static optimized version.
